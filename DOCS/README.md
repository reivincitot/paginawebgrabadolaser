# Laser Store Backend

Este proyecto es el backend de una tienda en línea, dividido en microservicios:

1. **Auth Service**: Autenticación de usuarios (JWT, Google, Facebook).
2. **Product Service**: Gestión de productos y categorías.
3. **Order Service**: Creación y seguimiento de órdenes.

## Requisitos

- Python 3.12.5
- PostgreSQL
- Node.js (para el frontend)
